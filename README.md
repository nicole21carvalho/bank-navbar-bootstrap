# 🏛️ Página inspirada no Banco do Brasil

Página web com barra de navegação, feita com **HTML, CSS e Bootstrap** como trabalho da avaliação N2.

## ✨ O que tem

- 🧭 Barra de navegação com links, menu suspenso e campo de busca
- 🎨 Estilo próprio em `main.css` sobre os componentes do Bootstrap

## 🛠️ Tecnologias

HTML · CSS · Bootstrap

## 🚀 Como executar

Baixe o repositório e abra o `index.html` no navegador.
